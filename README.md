#  Coin Tap Mini-Game

A fun and lightweight Unity mini-game where players tap on coins to score points. Built with clean architecture, polished UI, reusable loading screen, and full app flow from login to gameplay.

---

##  Project Overview

This project is a small but complete mobile-ready Unity app featuring:

- 🟢 Entry Screen → Login → Main Menu → Game
- ⏳ Reusable Loading Screen with fade & fake progress
- 🪙 30-second coin tap gameplay with score counter
- 🎧 Button click and coin collection SFX
- 🔁 Pause system (without Time.timeScale)
- 📱 UI built with TextMeshPro
- ✨ Animations, sounds, and clean UX
